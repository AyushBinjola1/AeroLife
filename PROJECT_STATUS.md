# AeroLife training results (2026-10-20)

Simulated turbofan data generated by NASA's C-MAPSS model; not measured engine data.

Dataset: NASA C-MAPSS FD001, downloaded from NASA's public archive. Owner authorized Decision A; faculty approval is not claimed. 80 training engines, 20 validation engines and 100 official test engines. Sequence length 30 cycles; target capped at 125 cycles for fitting; test errors use uncapped official labels at the final recorded cycle of each engine.

Three LSTM seeds (42, 43, 44) trained with early stopping. Seed 42 selected by lowest validation loss, independently of test performance. Saved bundle: artifacts/v0.2.0; 7073 parameters.

Selected LSTM test MAE: 13.47 cycles; RMSE: 19.14 cycles; PHM08 score: 652.31. MAE 95% engine-bootstrap interval: 10.89 to 16.15 cycles.

Random Forest baseline test MAE: 10.83 cycles; RMSE: 14.55 cycles. It outperforms the selected LSTM on this test set. The dashboard uses the LSTM selected using validation loss; no test-based reselection was performed.

All seven model rows are in reports/tables/test_comparison.csv; per-engine errors, seed histories and figures are in reports/. There is one test prediction per engine, so unit_avg_rmse equals MAE; pooled_rmse is the benchmark RMSE. test_endpoints.png shows official endpoint comparisons for all 100 engines. test_trajectories.png shows causal replay curves for the first 12 engines in a compact grid; all 100 histories are exported to reports/tables/test_replay_selected_rnn.csv. Replay curves do not change the official endpoint evaluation.

65 automated tests passed. Dataset alignment and final-window selection have dedicated tests. No sequence-length ablation was run. No real-engine validation or calibrated prediction intervals are available. Maintenance thresholds are teaching examples.
