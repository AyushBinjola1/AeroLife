# NASA C-MAPSS FD001

Simulated turbofan data generated by NASA's C-MAPSS model; not measured engine data.

Public archive: https://data.nasa.gov/docs/legacy/CMAPSSData.zip
NASA catalog: https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data
Retrieved 2026-10-20 directly from NASA. SHA-256 hashes are in data/provenance_manifest.json.

FD001 contains 100 training engines (20,631 rows) and 100 test engines (13,096 rows), one operating condition and HPC degradation. Each row has engine ID, cycle, three operating settings and 21 simulated sensor channels. The bundled readme's last sensor number is a typo: the actual 26-column files contain 21 sensor channels.

The project owner authorized simulation on 2026-10-20. This does not claim faculty approval.

Training engines are split into 80 training and 20 validation engines with seed 42. Official test engines remain separate. Training targets are cycles until the final failure cycle; official test labels are read from RUL_FD001.txt. Test failure times are reconstructed only for retrospective labels and are not observed events in the truncated test histories. Engine IDs and labels are excluded from inputs. Original cycle minus one defines both time_index and elapsed cycles.

Inputs are three settings and 21 sensors, with constant channels removed and normalization fitted on training engines only. Windows contain 30 cycles; target cap is 125 cycles. All 100 test engines have sufficient history. Test scoring uses one final window per engine, against uncapped official RUL. Validation uses all available windows. Maintenance thresholds are illustrative, not operational guidance.

Citation: A. Saxena, K. Goebel, D. Simon, N. Eklund (2008), Damage Propagation Modeling for Aircraft Engine Run-to-Failure Simulation, PHM08. Public NASA download; no separate license file is included in the archive.
